# framoid.com

The public gallery of Framoid Reflections, served free by GitHub Pages from the `main` branch.
Reflections are written in the "Framoid Reflections" project on claude.ai; this repository only holds the published ones.

## Layout

- `index.html`: home page; lists the Reflections in `reflections.json`.
- `reflections.json`: the gallery list, generated by `tools/publish.py`. Do not edit by hand.
- `r/<slug>/index.html` + `r/<slug>/reflection.json`: one published Reflection. The page is `template/index.html` with its own `<title>`.
- `template/index.html`: copy of REFLECTION_TEMPLATE.html from project knowledge.
- `CNAME`: the custom domain (framoid.com). `.nojekyll`: serve files as they are.

## Publishing

```
python3 tools/publish.py add path/to/reflection.json   # add or replace (slug = "number", lower-cased)
python3 tools/publish.py remove <slug>                 # unpublish
python3 tools/publish.py rebuild                       # after template/index.html changes
```

Then commit and push to `main`; the site updates within a minute or two.

## Template upgrades

When the template changes, copy the new REFLECTION_TEMPLATE.html to `template/index.html`, run `rebuild`, commit and push.
