# framoid.com

The public gallery of Framoid, served free by GitHub Pages. Every push to `main` runs `.github/workflows/publish.yml`, which publishes anything waiting in `inbox/` and deploys the site.
Reflections are written in the Framoid Studio (a claude.ai artifact); this repository only holds the published ones.

## Layout

- `index.html`: home page; lists the Reflections in `reflections.json`.
- `reflections.json`: the gallery list, generated by `tools/publish.py`. Do not edit by hand.
- `r/<slug>/index.html` + `r/<slug>/reflection.json`: one published Reflection. The page is `template/index.html` with its own `<title>`.
- `template/index.html`: copy of REFLECTION_TEMPLATE.html from project knowledge.
- `CNAME`: the custom domain (framoid.com). `.nojekyll`: serve files as they are.

## Publishing (no AI needed)

From the Studio: press Publish, copy the Reflection, open the GitHub link it gives (a new file in `inbox/`), paste, and commit. The workflow validates the file, moves it to `r/<number>/`, updates the gallery and deploys; the page is live a minute or two later. A file that is not a valid Reflection makes the workflow fail and stays in `inbox/` untouched.

Publishing again from the Studio opens the live page's own file, `r/<slug>/reflection.json`, for editing: paste over it and commit. Every push checks every `r/*/reflection.json`; a broken edit (bad JSON, not a Reflection, or a number that doesn't match the folder) fails the workflow and nothing is deployed, so the live site stays as it was.

By hand:

```
python3 tools/publish.py add path/to/reflection.json   # add or replace (slug = "number", lower-cased)
python3 tools/publish.py remove <slug>                 # unpublish
python3 tools/publish.py rebuild                       # after template/index.html changes
```

Then commit and push to `main`; the site updates within a minute or two.

## Template upgrades

When the template changes, replace `template/index.html` with the new REFLECTION_TEMPLATE.html and push. The workflow rebuilds every page from it on each push, so nothing else is needed.
